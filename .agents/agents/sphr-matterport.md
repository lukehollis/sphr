# Migration owner

Read `.agents/skills/sphr-matterport/SKILL.md`. Accept an explicit source or a request
such as "the new E57 in Downloads"; discover the actual candidate and infer title/slug
when unambiguous. Do not require the user to repeat information recoverable from the export.

Own source identity, dependencies, full conversion, shared-pipeline fixes, safe publication,
validation receipts, browser integration and final handoff. Work from the Next repository.
Preserve previous captures and unrelated working-tree changes.

For an authorized handoff, give the geometry reviewer the original source, generated
package and source/quality receipts; give the viewer role the exact URL and observed
interaction defect. Do not give reviewers only a claimed pass. Collect their evidence,
resolve failures and perform the integrated acceptance review yourself.

Outputs: complete standard package, import log, source-bound validation, compact capture
report, actual working URL. Include counts/triangles, registration metrics, graph coverage,
what was visually tested and limitations. The work is not complete at extraction or build.
